# Job Application Tracker

A full-stack web application to manage and track job applications in one place.

## Features

- Add job applications
- View all applications
- Edit applications
- Delete applications
- Search applications
- Filter applications by status
- Track application date
- Track interview date
- Store job links
- Add notes
- Dashboard statistics
- MySQL database
- Spring Boot REST API

## Tech Stack

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Java
- Spring Boot
- Spring Data JPA
- REST API

### Database
- MySQL

### Tools
- VS Code
- Maven
- Git
- GitHub
